# Website Design Prompt — EventFlow Home Page

Design a clean, modern SaaS landing page for **EventFlow**, an event feedback platform. The visual style should feel premium, trustworthy, and product-led.

## Overall Visual Style
- Modern SaaS aesthetic
- Minimal and polished
- Soft rounded corners
- Light background with subtle gradients
- Purple/blue as the primary brand color
- Use accent colors for ratings, sentiment, and feature highlights
- Clean typography with strong hierarchy
- Plenty of white space
- Soft shadows and subtle borders

## Layout Direction
Use a centered page container with generous spacing between sections. The design should feel airy, structured, and easy to scan.

## Color Palette
- Primary: vivid indigo / violet
- Secondary: soft lavender
- Background: very light gray / off-white
- Text: dark navy or near-black
- Muted text: gray
- Accent colors:
  - Yellow/orange for stars
  - Green for positive sentiment
  - Purple for primary brand elements

## Typography
- Use a modern sans-serif font
- Headline should be bold, large, and highly legible
- Section labels should be uppercase, small, and letter-spaced
- Body text should be clean and medium weight
- Use strong contrast between headings and descriptions

## Navbar Design
- White or very light translucent navbar
- Logo on left
- Nav links centered
- Primary CTA on right with rounded pill button
- Profile icon button beside CTA
- Active nav item highlighted with a soft pill background

## Hero Design
- Two-column layout
- Left side:
  - Small badge pill
  - Large bold headline
  - Short supporting paragraph
  - Two CTA buttons
  - Stats row underneath
- Right side:
  - Floating testimonial card
  - Card should feel elevated with soft shadow
  - Include avatar, verified badge, review text, rating bars, sentiment tag, and NPS badge
- Add subtle background gradient or glow behind hero content

## Card Design
- Rounded corners
- Light border or shadow
- Clean internal spacing
- Use badges and pills for metadata
- Keep the testimonial card visually rich but not cluttered

## Stats Section Design
- 3-column metric row
- Large bold numbers
- Small muted labels underneath
- Keep spacing balanced and minimal

## Live Pulse Ticker Design
- Slim horizontal strip
- Use small pills/cards for each live review
- Include event name, rating, and short quote
- Should feel dynamic but still clean

## Features Section Design
- Centered section heading
- 3 equal cards in a row
- Each card includes:
  - Icon in a soft colored square
  - Bold title
  - Short description
  - Text link with arrow
- Use subtle different accent tints for each card
- Cards should have soft shadows and rounded corners

## Analytics Section Design
- Two-column layout
- Left:
  - Small section label
  - Bold heading
  - Description paragraph
  - Avatar stack + live count
- Right:
  - Large chart card
  - Smooth line chart with gradient fill
  - Time markers below
  - Small badge for time range
- Chart should feel modern and data-focused

## CTA Banner Design
- Full-width rounded gradient banner
- Deep indigo/violet gradient
- White text
- Badge at top
- Large headline
- Supporting line
- Two buttons on the right:
  - White filled button
  - Transparent outline button
- Banner should have strong visual contrast against the rest of the page

## Footer Design
- Simple and minimal
- Logo and brand on left
- Nav links on right
- Bottom row with copyright and legal links
- Keep footer clean and unobtrusive

## UI Details
- Use pill buttons
- Use soft icon containers
- Use rounded cards
- Use subtle hover states
- Keep all alignment consistent
- Maintain strong spacing rhythm across sections
- Prioritize readability and visual hierarchy

## Responsive Design
- Desktop: multi-column layouts
- Tablet: stacked or 2-column adaptation
- Mobile: single-column stacking
- Ensure buttons, cards, and text scale cleanly
