# Website Design Prompt — EventFlow Events Page

Design a modern, clean **Events discovery page** for EventFlow with a premium SaaS feel. The page should make browsing events feel simple, visual, and trustworthy.

## Overall Visual Style
- Modern SaaS layout
- Light background
- White cards
- Indigo/violet primary color
- Soft shadows
- Rounded corners
- Clean typography
- Strong hierarchy between filters, cards, and CTAs

## Layout Direction
Use a centered container with a page header, filter bar, event card grid, load more section, trust highlights, and footer.

## Color Palette
- Primary: indigo / violet
- Background: very light gray / off-white
- Card background: white
- Text: dark navy / near-black
- Muted text: gray
- Accent colors:
  - Yellow/orange for ratings
  - Green for verified/NPS
  - Purple for category and UI accents
  - Soft blue/lavender for secondary badges

## Typography
- Use a modern sans-serif font
- Page title should be large and bold
- Section labels and badges should be compact
- Event titles should be strong and readable
- Descriptions should be smaller and lighter
- Buttons should use medium weight text

## Navbar Design
- Same navbar as the rest of the site
- Active “Events” nav item highlighted with a soft pill background
- Primary CTA button on the right
- Profile icon beside it

## Header Design
- Left side:
  - Small uppercase badge
  - Large page title
  - Short subtitle
- Right side:
  - 2 compact stat cards or inline stats
  - Include icon, number, and label
- Keep the header balanced and not too tall

## Search and Filters Design
### Search Input
- Wide rounded input
- Search icon on left
- Light background
- Muted placeholder text

### Status Pills
- Row of pill buttons
- One active pill with filled indigo background
- Inactive pills with light background and subtle border

### Category Pills
- Secondary row of filter pills
- Same visual style as status pills
- Active category should stand out clearly

### Sort Dropdown
- Compact dropdown on the right
- Rounded corners
- Light background
- Chevron icon

## Event Card Design
Each event card should include:
- Top image area
- Category badge overlaid on image
- Location pill overlaid at bottom left of image
- Format/status badge overlaid at bottom right of image
- White content body below image
- Date/time row with icon
- Event title
- Venue line
- Description
- Rating row
- Optional badge
- Two action buttons at the bottom

### Image Area
- Large rounded-top image
- Dark overlay for readability
- Category badge in top-left
- Location and format badges along bottom edge

### Content Area
- Clean white background
- Balanced padding
- Date and time in small gray text
- Event title in bold
- Venue in muted text
- Description in medium gray
- Rating stars and review count
- Badge aligned to the right when needed

### Buttons
- “View Details”
  - Light neutral button
- “Give Feedback”
  - Indigo primary button
  - Icon on left
- Buttons should sit side by side near the bottom of the card

## Grid Layout
- Desktop: 3 cards per row
- Tablet: 2 cards per row
- Mobile: 1 card per row
- Maintain consistent card heights and spacing

## Load More Section
- Centered button with chevron
- Small helper text underneath
- Keep this section visually light

## Trust Highlights Section
- 3-column layout
- Each item includes:
  - Icon in a soft circular or square container
  - Bold title
  - Short supporting description
- Use subtle dividers or spacing to separate items
- Keep the section clean and informative

## Footer Design
- Same footer as the rest of the site
- Minimal and clean
- Logo and nav on top
- Copyright and legal links below

## Responsive Design
- Desktop:
  - Full filter bar
  - 3-column event grid
  - 3-column trust highlights
- Tablet:
  - 2-column event grid
  - Filters can wrap
  - Trust highlights can remain 3 columns or compress
- Mobile:
  - Single-column cards
  - Stacked filters
  - Full-width search
  - Stacked CTAs if needed
  - Single-column trust highlights

## UI Details
- Use consistent border radius
- Use soft shadows only
- Keep all card content aligned
- Use badges sparingly but clearly
- Maintain clean spacing between sections
- Make ratings and CTAs easy to spot
