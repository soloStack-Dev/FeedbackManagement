# Website Design Prompt — EventFlow Feedback Page

Design a polished, modern feedback form page for **EventFlow** with a clean SaaS aesthetic. The page should feel simple, trustworthy, and easy to complete.

## Overall Visual Style
- Minimal SaaS design
- Light background
- White content cards
- Rounded corners
- Soft shadows
- Indigo/violet primary color
- Muted gray helper text
- Clean and spacious layout

## Layout
Use a centered page layout with a wide form card as the main focal point. Keep generous spacing between sections so the form feels approachable.

## Color Palette
- Primary: indigo / violet
- Background: very light gray or off-white
- Card background: white
- Text: dark navy / near-black
- Helper text: gray
- Input backgrounds: very light lavender
- Star ratings: yellow/orange
- Selected states: strong indigo accent

## Typography
- Use a modern sans-serif font
- Page heading should be large, bold, and centered
- Section labels should be medium weight and clear
- Helper text should be smaller and lighter
- Input placeholder text should be subtle

## Navbar Design
- Same navbar as the rest of the site
- Light background
- Center nav links
- Active “Feedback” item highlighted with a soft pill background
- Primary CTA button on the right
- Profile icon beside CTA

## Header Design
- Center aligned
- Small pill badge at the top
- Large bold title
- Short centered description underneath
- Keep the header compact but visually strong

## Form Card Design
- Large white rounded container
- Soft shadow
- Plenty of internal padding
- Form fields arranged vertically with clear spacing
- Inputs should have subtle rounded corners
- Use light lavender input backgrounds for softness

## Input Design
### Select Dropdown
- Full-width dropdown
- Rounded corners
- Light background
- Dropdown icon on the right
- Placeholder text in muted gray

### Star Rating
- Large clickable stars
- Default state: light gray stars
- Hover/filled state: yellow/orange stars
- Add small helper text like “Click to rate”

### Textareas
- Full-width
- Rounded corners
- Light background
- Muted placeholder text
- Enough height for multi-line responses

## Detailed Evaluation Cards
- 3-column card layout on desktop
- Each card includes:
  - Icon
  - Category title
  - Subtext
  - Star rating
  - Numeric rating label like “5/5”
- Cards should have:
  - Soft background
  - Rounded corners
  - Light shadow or border
- Use equal width and balanced spacing

## Recommendation Option Cards
- Two side-by-side selectable cards
- Each card includes:
  - Circular icon
  - Title
  - Subtext
  - Selection indicator
- Selected card:
  - Strong indigo border or fill accent
  - Filled radio indicator
- Unselected card:
  - Light background
  - Subtle border

## Buttons
### Secondary Button
- “Clear Entries”
- Simple text button or subtle neutral button

### Primary Button
- “Submit Feedback”
- Bold indigo button
- Rounded corners
- White text
- Arrow/send icon on the right
- Strong visual emphasis

## Privacy Note
- Small centered text under the form
- Lock icon
- Muted gray color
- Should feel reassuring and unobtrusive

## Footer Design
- Same footer style as home page
- Simple, clean, minimal
- Logo and nav on top row
- Legal/copyright row underneath

## Responsive Design
- Desktop:
  - Centered form card
  - 3-column detailed evaluation cards
  - 2-column recommendation cards
- Tablet:
  - Slightly reduced form width
  - Cards may remain in columns or wrap depending on space
- Mobile:
  - Single-column layout
  - Full-width inputs
  - Stacked cards
  - Stacked recommendation options
  - Primary actions full width or easy to tap

## UI Details
- Use consistent border radius across inputs and cards
- Keep all spacing aligned
- Use soft shadows, not heavy ones
- Maintain strong hierarchy between headings, labels, and helper text
- Keep the page visually calm and conversion-friendly
