# Website Development Prompt — EventFlow Home Page

Build a modern, responsive home page for a web app called **EventFlow**, an event feedback and review platform.

## Goal
Create a polished landing page that explains the product, builds trust, and encourages users to explore events or submit feedback.

## Tech / Structure
- analyze the package.json file
- Use reusable components:
  - Navbar
  - Hero section
  - Stats section
  - Live pulse ticker
  - Features section
  - Analytics/dashboard section
  - CTA banner
  - Footer
- Make the layout fully responsive for desktop, tablet, and mobile.
- Keep spacing consistent and use a design system style approach.
